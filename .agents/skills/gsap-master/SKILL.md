# GSAP Master Animation Suite

Official GreenSock Animation Platform (GSAP) skills and runbooks for AI coding agents.

## Included Modules

- **gsap-core**: Tween methods (to, from, fromTo), easing, duration, stagger, matchMedia.
- **gsap-scrolltrigger**: Scroll-driven animation, parallax, pinning, scrub triggers.
- **gsap-react**: React & Next.js integration with the `useGSAP` hook, refs, and cleanup.
- **gsap-timeline**: Chaining tweens, labels, sequencing, relative timing, nested timelines.
- **gsap-plugins**: Flip, Observer, Draggable, MotionPath, TextPlugin, SplitText.
- **gsap-frameworks**: Vue, Nuxt, Svelte, Astro integration patterns.
- **gsap-performance**: Will-change, layout thrashing prevention, transforms over layout properties, GPU acceleration.
- **gsap-utils**: Clamp, mapRange, wrap, interpolate, snap, random, pipe.

See `modules/<module-name>/SKILL.md` for dedicated deep-dive instructions for each specialized module.

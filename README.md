## ✨ Features & Architecture

- **Materiality & Palette**: Deep Monolithic Basalt Slate (`#0c0d10`), Brushed Champagne Bronze (`#c5b49a`), Warm Platinum (`#e8dfd1`), and Editorial Travertine Inverted Plates (`#f4f4f7`).
- **Cinematic Film Integration**: Embedded 4K drone cinematography showcasing spatial geometry and structural cantilevers.
- **Dynamic Multi-Scene Hero**: Interactive scene switching (Alps Spire, Azure Cantilever, Villa Solaris) with real-time architectural blueprint dossiers and instant *Cinematic Film Mode*.
- **Tactile 3D Interactions**: Physics-based cursor trailing, 3D card perspective tilt, and GSAP scroll-triggered reveals.
- **Specimen & Estimator Labs**: Interactive geological materiality inspection and institutional scope/budget estimator.

## 🚀 Quick Start (Local Development)

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/jaygupta-sys/YR-CONSTRUCTIONS.git

# Navigate to project directory
cd YR-CONSTRUCTIONS

# Start a local HTTP server
python -m http.server 8000
```

Then visit **`http://localhost:8000`** in your browser.
